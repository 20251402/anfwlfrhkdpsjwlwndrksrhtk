# 물질과 에너지 OMR

2026-2 환일고 중간고사 물질과 에너지 예상문제(원본·변형1~5, 각 71문항)를
한 문항씩 풀고 즉시 채점하는 학습 사이트. 로그인한 학생만 풀 수 있고,
풀이 기록은 서버에 저장된다.

## 배포 (GitHub → Netlify)

1. 이 폴더를 통째로 GitHub 저장소에 올린다.
2. Netlify에서 `Add new site → Import an existing project`로 저장소를 연결한다.
   Build command는 비우고 Publish directory는 `.` — `netlify.toml`에 이미 적혀 있다.
   Functions 디렉터리(`netlify/functions`)도 같은 파일에서 잡아 준다.
3. **환경 변수 하나를 반드시 넣는다.** Site configuration → Environment variables:

   | 이름 | 값 | 쓰임 |
   |---|---|---|
   | `ADMIN_TOKEN` | 아무 긴 문자열 (예: 40자 랜덤) | 관리 페이지 접근 토큰 |
4. 배포하면 첫 요청 때 아래 6개 계정이 자동으로 만들어진다. 첫 비밀번호는 모두 `1234`이고,
   처음 로그인하면 반드시 바꾸게 되어 있다.

   | 학생 | 아이디 |
   |---|---|
   | 김민재 | `hwanil1` |
   | 박성현 | `hwanil2` |
   | 정해유 | `hwanil3` |
   | 김범준 | `hwanil4` |
   | 김윤수 | `hwanil5` |
   | 김진욱 | `hwanil6` |

## 관리 페이지

`https://<사이트 주소>/admin.html` 에서 `ADMIN_TOKEN`을 넣으면

- 접속 중 여부, 마지막 로그인, 푼 문항 수·오답 수
- 계정 만들기 / 삭제 / 비밀번호 `1234`로 초기화 / 강제 로그아웃

**비밀번호는 조회할 수 없다.** salt + scrypt 해시로만 저장하고 되돌릴 수 있는 형태로는
어디에도 남기지 않는다. 학생이 잊어버리면 `1234`로 초기화해 주면 되고, 그 학생은 다음
로그인 때 새 비밀번호를 다시 정하게 된다.

학생은 웹에서 계정을 만들 수 없다. 관리자 토큰이 있어야만 만들고 지울 수 있다.

## 동작 규칙

- **한 계정은 한 기기에서만.** 이미 다른 기기에서 접속 중이면 로그인이 막히고,
  "다른 기기 로그아웃하고 여기서 로그인" 버튼으로만 넘어올 수 있다.
  20분 넘게 아무 활동이 없으면 그 세션은 자동으로 풀린다.
- **로그인 유지.** 체크하면 60일, 안 하면 브라우저를 닫을 때까지.
- **첫 로그인 시 비밀번호 변경.** 현재 비밀번호 + 새 비밀번호 + 새 비밀번호 확인,
  세 칸을 모두 통과해야 문제 화면으로 넘어간다.
- **기록 동기화.** 답을 낼 때마다 서버에 저장되므로 다른 기기에서 로그인해도 이어서 풀 수 있다.
- **문항별 소요 시간**을 함께 기록한다 (문항이 열린 순간부터 제출까지).

## 시험 대비 마무리 출제

**2026년 9월 30일 오후 6시(KST)** 에 시작 화면에서 열린다. 그전에는 남은 시간만 보인다.

고르는 기준은 두 가지다.

- 한 번이라도 틀린 문항 (또는 두 번 이상 제출한 문항)
- 같은 문항을 푼 **전체 학생 평균보다 오래 걸린** 문항

여섯 세트를 모두 푼 학생에게는 원본과 변형을 섞어서, 아직 안 푼 변형이 있는 학생에게는
원본과 **안 푼 변형**으로 출제한다.

## 구성

```
index.html                  앱 (CSS/JS 인라인)
admin.html                  관리 페이지
data.json                   426문항의 형식·정답·이미지 좌표
img/*.jpg                   문제·해설 이미지 시트 (세트별 9장, 한 장에 8문항)
netlify/functions/api.js    로그인·기록·관리·시험대비 API (Functions v2, ESM)
netlify.toml                배포 설정 (/api/* → 함수로 연결)
package.json                @netlify/blobs 의존성
```

기록은 Netlify Blobs에 저장된다. 따로 데이터베이스를 붙일 필요가 없다.

## 알아 둘 점

- 비밀번호는 계정마다 다른 salt를 붙인 scrypt 해시로만 저장한다. 관리자도, 서버 로그도,
  Blobs 데이터를 통째로 열어 봐도 평문을 알 수 없다. 복구 수단은 `1234`로 초기화하는 것뿐이다.
- `data.json`과 문제 이미지는 로그인 없이도 주소를 알면 받을 수 있다. 풀이·채점·기록만 로그인 뒤에 열린다.
